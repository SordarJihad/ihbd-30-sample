# MVP

## Core action
Log a Messenger/Facebook-live order in under ten seconds (customer, phone, item, size, price, COD).

## Must-have
- Seller signup and login
- Add an order from the phone (one short form)
- Today's order list with status (new, packed, sent)
- Courier list for tonight (copy or download)
- Mark COD as paid when the courier pays

## Not now
- Automatic import from Messenger (needs Meta app review)
- Courier API integration (Pathao/Steadfast)
- Multiple staff accounts
- COD reconciliation reports
- Bangla voice input

## Success metric
One real seller logs every order for 3 days in a row and makes her courier list from Order Khata instead of the khata.

Free during the challenge. Later maybe a small monthly fee: two sellers already pay a part-time helper to copy orders, so saving that hour has real value. I will ask on the first calls instead of guessing a number now.
