# Order Khata
Order book for Facebook page sellers: log Messenger orders fast, make tonight's courier list, track unpaid COD.

## Run locally
```
npm install
npm run dev
```
Open http://localhost:3000

## Week 1
Built: idea + 5 interviews, MVP scope, landing page with waitlist (Supabase, server action), email login, protected dashboard.
